# RX-7 Interior Redesign

## Overview
Full redesign and fabrication of the centre console for a 1988 Mazda RX-7 FC3S. The goal was to modernize the interior functionality while preserving the vintage aesthetic of the vehicle.

## Features
- Foldable Apple Carplay screen taking over previous warning light housing. 
- USB charging outlet for modern device compatibility
- Custom designed air vents
- Repositioned factory warning lights with rewired connections
- 5 degree draft angle towards driver for improved ergonomics

## Tools & Skills Used
- **CAD Software:** Fusion 360
- **Fabrication:** FDM 3D Printing
- **Electrical:** Soldering, wiring relocation
- **Measurement:** Hand measurements taken from original OEM console to ensure accurate fitment

## Design Philosophy
Modern features were deliberately integrated without compromising the classic look of the FC3S interior. All modifications maintain factory mounting points and preserve the original character of the vehicle.
